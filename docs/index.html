    Transmission outside the amateur bands

    This release enables transmission outside the amateur radio bands. You alone are responsible for transmitting only on frequencies, with powers and in modes that your licence and your national regulations allow. Unlicensed or out-of-band transmission may be illegal and can interfere with other services.

    Includes the custom A/B bootloader

    Besides the main firmware, this release replaces the radio's small boot loader (the first 64 KiB of flash) with a custom A/B slot-toggle bootloader. The radio's own SD-card updater writes it once, when the update starts. The boot loader exists in a single copy: if power is lost during that write, the radio will not start and can only be recovered with an external flash programmer (e.g. CH341A, chip desoldered or clipped). Use a reliable power supply and do not interrupt the update.

    The firmware keeps two slots (A and B), as Icom's updater already alternates between them. The custom bootloader lets you switch to the other slot (e.g. back to the previous firmware):

    • IC-9700: hold POWER while connecting the DC supply, for about 5 seconds.
    • IC-705: at power-on keep holding POWER for about 3 seconds more, until the LED blinks.

    Installing any official Icom firmware afterwards restores Icom's own boot loader.

    About this firmware (transverter support, scope dB/div, A/B bootloader, extended TX)

    These releases are built for microwave transverter operation: the radio works as the IF rig for an external transverter (for example 10, 24, 47, 76 or 122 GHz). It shows and reports the real microwave frequency, and it can adapt its transmit behaviour to each transverter.

    Transverter support (TRV1-TRV8)

    • Up to eight transverters. For each one you set the RF frequency (on the microwave band) and the IF frequency (the band the radio actually tunes). Select the active transverter in the radio's menu; the settings are kept after power-off.
    • The display shows the real RF frequency, up to 122 GHz, in the radio's normal frequency style.
    • CI-V reports and accepts the RF frequency, so logging and control software sees the microwave frequency, not the IF. Above 1.4 GHz the CI-V frequency uses the 6-byte format, as on the IC-905.
    • IC-9700: IF on 2 m, 70 cm or 23 cm. Menu: SET > Transverter.

    IC-9700: MAIN / SUB, DUAL watch and SAT mode

    • The active transverter is chosen separately for MAIN and SUB (SET > Transverter > MAIN Active / SUB Active), e.g. MAIN = 10 GHz via 144 MHz and SUB = 24 GHz via 432 MHz. A receiver shows its RF only while its frequency is in that transverter's IF band.
    • DUAL watch: both readouts show their own RF frequency at the same time.
    • MAIN/SUB exchange: the transverter selection moves together with the bands, because each transverter is wired to its band's antenna connector.
    • Transmit settings (power limit, TX delay, PTT inhibit) follow the receiver that transmits: MAIN Active in normal operation, SUB Active in SAT mode (the IC-9700 transmits on SUB in satellite mode). Switching SAT mode on or off does not swap the selections.

    Scope: finer vertical scale

    • Scope Set > Scope dB/div: 10 (stock), 6, 3 or 1 dB per division for the spectrum and the waterfall, to see weak signals. At 6/3/1 dB the noise floor is found automatically and placed about one division above the bottom (separately for MAIN and SUB on the IC-9700); REF shifts the picture up or down.
    • The scope data sent over CI-V / LAN / WLAN to PC software is unchanged.

    Transmit control per transverter

    • Maximum TX power (100 / 50 / 25 / 10 / 5 %). It protects the transverter input from overdrive and never raises power above the radio's own setting.
    • TX delay up to 300 ms in all modes. RF output is held back after the SEND line switches, so the sequencer, coax relays and PA have time to switch before drive is applied.
    • PTT inhibit (IC-9700). Transmission is blocked completely for a transverter that is used for receive only.
    • When no transverter is active, the radio transmits exactly like the original firmware.

    Extended TX frequency ranges (IC-705)

    Many microwave transverters use local oscillators whose IF does not fall on the radio's standard amateur-band TX segments, or they use an IF on another band. That is why the IC-705 releases extend the radio's TX ranges, so that such an IF can be used. These ranges exist for driving a transverter. You alone are responsible for transmitting only where your licence and national regulations allow.

    Safe updates: A/B bootloader

    The radio keeps both the new and the previous firmware. If a new version does not work, you can switch back without tools:

    • IC-9700: hold POWER while connecting the DC supply (about 5 s).
    • IC-705: hold POWER at power-on until the LED blinks (about 3 s).

    A slot that is structurally damaged is detected, and the radio falls back to the other slot automatically.

    Before you connect a transverter

    On a dummy load, measure the SEND-to-RF delay (with a scope) and the output power for every transverter slot you plan to use.

    SD-card apps: decoders, beacon, QSO mode, APRS

    The ICAP releases run digital-mode apps from the SD card: Q65, FT8, JT4, PI4 and WSPR decoders on the radio's DECODE screen (WSJT-X-style output), a beacon, QSO mode, PSKReporter spotting and APRS. They are optional — the firmware works without them. The firmware image and the bundle belong together: use the bundle with the same release number.

    • IC-705 E — SD-apps bundle 20261119v14 (for firmware 20261119v14 only)
    • IC-705 J — SD-apps bundle 20261119v14 (for the J firmware 20261119v14 only; ICAPSPOT.BIN / ICAPCOLD.BIN differ from E)
    • IC-9700 — SD-apps bundle 20261119v14 (for firmware 20261119v14 only)

    New in 20261119v14

    • QSO mode verified on the IC-705 E and the IC-9700. A tap on the TX? line that comes too early is no longer ignored silently: the screen shows QSO: wait 1 s, tap again.
    • Longer hold for CQ: the time between the red (beacon) and the green (CQ) frame is about three times longer, so CQ is not armed by accident.
    • TX refused: <reason> on the DECODE screen names the condition that blocks a transmission.
    • APRS in the firmware: MENU > SET > GPS > GPS TX Mode has a 4th choice APRS (next to D-PRS / NMEA): position beacon as 1200 Bd AFSK on the current frequency, FM only; received APRS stations go to the radio's RX History. It uses APRS.APP from the bundle; the firmware starts and stops it by itself with the menu choice (no need to open it in Apps). Received frames are also written to Apps\APRS.LOG.

    How to use it

    1. Patch the official .dat above and install it with Icom's normal SD-card firmware update.
    2. Unzip the bundle for your radio and copy all its files to the Apps folder of the SD card (\IC-705\Apps\ or \IC-9700\Apps\), replacing older ones. The .BIN files work only with the matching firmware. IC-9700: power-cycle the radio afterwards.
    3. Set your own callsign and Maidenhead locator on the radio (MY call, GPS position or manual). The firmware carries no personal data.
    4. To transmit, the radio needs: USB-D mode, DATA MOD = WLAN (IC-705), the SD card inserted, no remote (LAN) session, and its clock locked to the second (the app waits for it). If something is missing, the DECODE screen says TX refused: <reason>.
    5. Start an app in MENU > SET > Apps; decodes appear on the DECODE screen. Each mode's settings are in its .CFG file and in DECODE > SET (submode, PSKREPORT on/off).
    6. Beacon: in a decoder mode, hold the mode tile in the emission popup until a red frame appears and release.
    7. CQ: keep holding past the red frame until it turns green, then release — CQ in every second period.
    8. QSO: tap a decoded line, wait about a second, tap the proposed TX? line — the radio sends that one message (QSO: TX armed). One transmission per tap; the radio never advances a QSO by itself. PTT, EXIT or TRANSMIT stop at once.
    9. QSOs are appended to Apps\ICAPQSO.ADI (ADIF) for import into your logbook. Spots go to PSKReporter automatically (UDP to report.pskreporter.info) when call, locator and network are present.
    10. APRS: set MENU > SET > GPS > GPS TX Mode to APRS, tune an FM channel (e.g. 144.800 MHz in Europe) and set the interval in GPS Auto TX. The beacon needs a valid position (GPS or manual). Turn NR (Noise Reduction) off on that receiver — NR distorts the AFSK tones and nothing is decoded.

    Make the first transmissions on a dummy load. These apps are the project's own code, not Icom software (decoders: GPL-3.0, partly derived from WSJT-X; APRS: MIT). APRS® is a registered trademark of APRS Software and Bob Bruninga, WB4APR.

    How it works

    1. The page computes the MD5 of your file and checks it against the list of official Icom files.
    2. It decodes the firmware container (autokey transform + LZSS), exactly like the Python tools in the repository.
    3. It applies the release's patch file. A patch holds only the project's own code and data, plus references like “copy N bytes from address X of the official image” — no Icom firmware is distributed.
    4. It re-compresses the image, re-seals the container (MD5) and compares the MD5 of the result with the MD5 of the build that was tested on a radio. Only an identical file is offered for download.
    5. Install it with Icom's normal SD-card firmware update procedure, using this file instead of the official one.

    Privacy

    Your firmware file is processed entirely on your computer, in a background worker in this browser tab. It is never uploaded. The page loads only its own static files (HTML, CSS, scripts and patch descriptions) from this site; it uses no analytics, cookies, external fonts or third-party scripts. The “Translate this page” link opens Google Translate in a new tab only if you click it.

    You can also run the same process offline with the repository's icom_patch.py; both produce the same MD5.
